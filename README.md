# n8n Free Automation Templates — 5000+ Workflow Library

A large collection of reusable **n8n automation workflow templates** organized around platforms, integrations, triggers, AI workflows, operations, marketing, research, security, and other automation use cases.

## What you'll find

- Thousands of ready-to-explore n8n workflow JSON files
- Templates grouped by platforms and services
- AI agent and OpenAI workflow examples
- Webhook, API polling, cron and schedule-trigger automations
- Marketing, social media, operations, research and security workflows
- Integrations spanning popular SaaS and cloud platforms

## Usage

1. Browse the folders and choose a workflow relevant to your use case.
2. Download the `.json` workflow file.
3. Import it into n8n.
4. Review every node, credential, URL and environment-specific value before enabling the workflow.

> Templates should be treated as starting points. Never import third-party automation into a production environment without reviewing credentials, permissions, webhooks, API calls and destructive actions first.
